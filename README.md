# learn-gpu-programming

This repo is created for me to learn programming and profiling on GPUs.

The GPUs (and microarchitectures) I will be currently using and optimize my program on:
- 5070Ti Laptop & 5090 (Blackwell Consumer, sm120)
- H200 (Hopper, sm90)

I am also planning to use B200 (Blackwell, sm100) in the future.

The main programming language I will be learning is Tilelang, where all the program will be written in. I am also interested in CUDA/CUTLASS and Triton and some program will be written in these languages.

This repo is inspired by [gau-nernst/learn-cuda](https://github.com/gau-nernst/learn-cuda).
